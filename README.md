<h1>No You Decide</h1>
Ceci est un petit projet pour aider les gens indécis à prendre des décisions. Ce projet a été codé avec React et utilise FireBase pour la base de données.
<br/>
https://qdacier.github.io/NoYouDecide/

<h2>Fonctionalitées :</h2>
<li>créer un lobby</li>
<li>rejoindre un lobby</li>
<li>ajouter des choix dans la roue</li>
<li>tourner la roue</li>
<li>changer le thême du site</li>
<br/>
<i>On ne réinvente pas la roue</i> 🤪. Sans faire de mauvais jeux de mot 🫠, j'ai fait cette application web pour mes proches, pour moi même, pour me pratiquer et surtout pour en apprendre un peu plus (Comme avec la génération de code QR, la notion de lobby en app web et l'utilisation de Firebase).
